# Sims 4 Autonomy Mod

Custom tuning mod for Sims 4 sleep/nap control and need decay adjustment.

## Phase 1: Sleep/Nap Control
- Restrict sleep/nap to set time windows
- Adjustable exhaustion thresholds
- Global settings across all saves

## Project Structure
- `mod/` - Mod source files
- `docs/` - Specifications and documentation
- `README.md` - Project overview
